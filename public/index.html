All 6 Tuning Knobs for Pi Guard Optional portable runtime in .guard-runtime · API spend stays off by default
Auto-Priority Order/guard-order auto puts expiring surplus plans first and exhausted accounts last across AGY, Codex, and Claude.
Task Routing Rules/guard-rule or plain English ("use agy then codex") steers routing locally in 0ms with zero model tokens.
Work ModesSwitch continuous, preserve, or max to tighten context ceilings, output caps, and reasoning effort on the fly.
Tool Archive & LoopsTrims oversized tool output before replay, trips repeated failing calls, and allows one bounded repair attempt.
Silent Refusal FallbackDetects quota-wall text replies, marks the bucket exhausted, and automatically fails over to the next open model or plan.
Unattended Watchdognpm run guard:watch restarts a dead controller, refreshes stale quotas, and resumes stalled overnight runs from handoffs.
