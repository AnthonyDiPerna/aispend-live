    1. Start the local controller with npm run guard.
    2. Install the extension using integrations/pi/README.md.
    3. Sign in to each provider in Pi, then run /guard. Models are selected automatically.
    4. Guard activates aispend/guard. Every routed request checks these rules.

    Reading an allowance and connecting a Pi model are separate. Antigravity monitoring works through agy; routing needs a compatible Pi subscription connector. API fallback requires explicit dollar caps. Radius is a separate gateway, not a transfer of your plan allowances.

    Guarded tasks

    Task IDs are hashed. The dashboard receives counters and decisions, not prompts, tool output, credentials, or repository paths. Renewing a task budget is a deliberate local action; it does not refill a provider allowance.

    Recent decisions

    In interactive Pi, allowance pauses wait for a fresh reading and resume automatically. Use /guard-hold to cancel waiting. Repeated operations get one bounded repair; exhausted budgets and repeated repair failures pause for review. No savings percentage is promised; cached tokens are useful when the context is still relevant.
